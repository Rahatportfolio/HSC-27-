স্থানীয় JSON উদ্ধার / Local JSON recovery

অ্যাপের মূল ফাইল না খুললেও এই আলাদা পাতায় একই অ্যাপ/browser-এর সেভ করা JSON অপরিবর্তিত দেখা, কপি বা ডাউনলোড করা যাবে। কিছুই নিজে থেকে মুছবে, বদলাবে বা আপলোড করবে না। Android System WebView ও Chrome আপডেট করে আবার চেষ্টা করো।

This independent page reads raw localStorage JSON only, not SQLite or another browser/app profile. It does not validate, repair, restore, upload or change your data.

অ্যাপ uninstall বা Clear data করবে না। এটি পূর্ণ ব্যাকআপ নয়; ছবি, PDF ও ভিডিওর আসল bytes এখানে থাকবে না। মূল ডিভাইস, Full backup ও আলাদা PDF রাখো।
Do not uninstall or clear app data. This is not a full backup: JSON contains metadata, not images, PDFs or video bytes. Keep the original device and verified full-media backups.

২। আলাদা কপি রাখো / Keep a separate copy

অ্যাপ/WebView-এ ডাউনলোড সমর্থিত না হলে উপরের ঘর চেপে ধরে সব লেখা বেছে কপি করো, তারপর নিরাপদ ফাইলে রাখো। ডাউনলোডের বোতাম চাপা মানেই ফাইল সেভ নিশ্চিত নয়—ফাইল খুলে মিলিয়ে নাও। উদ্ধার কপিতে ত্রুটি থাকলে সেটিও অপরিবর্তিত থাকবে; সেটিকে যাচাই করা backup বলা হচ্ছে না।

If copying/downloading is blocked, select and copy the text manually. Verify the saved file yourself. An old or corrupt snapshot is preserved as evidence, not certified as a restorable backup. Use Settings → Full backup after the app works again.
